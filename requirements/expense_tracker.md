A personal expense tracker for a single user.
The user can record an expense with an amount, a date, a category (such as food, rent, travel) and an optional note.
The user can edit or delete an expense they recorded.
The user can set a monthly budget for each category.
The system should report total spending per category for any month, and show how much budget is left in each category.
The system should warn when spending in a category goes over its monthly budget.
The system should list expenses filtered by month and by category, newest first.
The system should reject negative amounts and expenses with no category.
