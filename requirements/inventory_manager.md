An inventory manager for a small warehouse.
The user can add products with a SKU, a name, a unit cost and a reorder level.
The user can record stock received and stock shipped for a product, with a quantity and a date.
The system should report the current quantity on hand and the total stock value (quantity times unit cost) for each product and for the whole warehouse.
The system should list the products whose quantity on hand is at or below their reorder level.
The system should show the history of stock movements for a product.
The system should prevent shipping more units than are on hand, and reject duplicate SKUs.
